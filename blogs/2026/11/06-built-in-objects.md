# 内置对象

| 知识点        | 典型写法                        |
| ------------- | ------------------------------- |
| 日期类型      | `Date`                          |
| 正则类型      | `RegExp`                        |
| 错误类型      | `Error`                         |
| DOM 元素      | `HTMLElement`、`HTMLDivElement` |
| DOM 集合      | `NodeListOf<T>`                 |
| 鼠标事件      | `MouseEvent`                    |
| 异步结果      | `Promise<T>`                    |
| Canvas 元素   | `HTMLCanvasElement`             |
| Canvas 上下文 | `CanvasRenderingContext2D`      |

## 口诀

> **日期正则加错误，DOM 事件 `Promise`，Canvas 两件套。**
