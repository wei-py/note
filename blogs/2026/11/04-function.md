# 函数扩展

| 功能       | 写法                             |
| ---------- | -------------------------------- |
| 参数类型   | `name: string`                   |
| 返回值类型 | `(): string`                     |
| 可选参数   | `age?: number`                   |
| 默认参数   | `age: number = 18`               |
| 函数接口   | `(a: number, b: number): number` |
| 剩余参数   | `...args: string[]`              |
| 函数重载   | 多个签名加一个实现               |

## 口诀

> **参数类型返回值，可选默认和剩余，重载签名要成对。**
