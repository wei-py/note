# Helix 快捷键速查

根据 `/Users/wx/.config/helix/config.toml`、本机 Helix 25.07.1 内置教程及 Herdr 快捷键文档整理，记录日期：2026-11-13。此文档为配置快照，不会自动同步。自定义键位完整列出；默认键位仅摘录常用项。

## 按键与模式说明

- `Ctrl` = ⌃，`Alt` = Option / ⌥，`Cmd` = ⌘。大写字母表示按住 Shift，例如 `G` = Shift+g。
- `qq`、`miw`、`[e` 等表示依次按键，不是同时按下；`Ctrl+d` 等带加号的写法表示组合键。
- 除非单独注明，下文操作从普通模式（NOR）开始。插入模式为 INS，选择模式为 SEL。
- Helix 的核心是“先选择，再操作”：例如 `miw` 选中单词，接着 `c` 修改、`d` 删除、`y` 复制。不是 Vim 的 `diw` 顺序。
- `:` 命令输入后需要按 Enter 执行。

## 当前自定义快捷键

### 普通模式（NOR）

| 快捷键 | 功能 | 配置动作 |
|---|---|---|
| `Ctrl+d` / `F12` | 将当前选区设为搜索内容，再增加选中下一个匹配 | `search_selection` → `extend_search_next` |
| `H` | 移至行首，包含前导空白；不是首个非空白字符 | `goto_line_start` |
| `L` | 移至行尾 | `goto_line_end` |
| `G` | 跳到文件末尾 | `goto_file_end` |
| `qq` | 格式化当前文档，取决于该语言的 formatter / LSP 是否可用 | `:format` |
| `rr` | 显示单词跳转标签，再输入标签跳转；与默认 `gw` 相同 | `goto_word` |
| `[e` | 上一个诊断 | `goto_prev_diag` |
| `]e` | 下一个诊断 | `goto_next_diag` |

### 插入模式（INS）

| 快捷键 | 功能 | 配置动作 |
|---|---|---|
| `jk` | 返回普通模式 | `normal_mode` |
| `Alt+x` | 返回普通模式 | `normal_mode` |

### 选择模式（SEL）

| 快捷键 | 功能 | 配置动作 |
|---|---|---|
| `Ctrl+d` / `F12` | 将当前选区设为搜索内容，再增加选中下一个匹配 | `search_selection` → `extend_search_next` |
| `H` | 移至行首 | `goto_line_start` |
| `L` | 移至行尾 | `goto_line_end` |
| `jk` | 返回普通模式 | `normal_mode` |

### 自定义覆盖与注意事项

- 普通模式的 `Ctrl+d` 已改为多选，不再是默认的向下半页滚动。
- 普通模式的 `q` 已成为 `qq` 的前缀，不再直接回放宏；`Q` 的默认录制功能并不因此变成格式化。
- 普通模式的 `r` 已成为 `rr` 的前缀，不再支持默认的 `r` + 字符来替换选区字符。修改文本可用 `c`，用剪贴板内容替换选区可用 `R`。
- 插入模式的 `j`、选择模式的 `j` 已成为 `jk` 的前缀：不能再把它们视为无条件直接输入 `j` / 向下移动。选择模式需要向下扩选时可用 `↓`。
- 当前配置 `default-yank-register = "+"`，默认复制 / 粘贴使用系统剪贴板；删除、修改选区也可能更新剪贴板。希望不复制删除内容时用 `Alt+d` / `Alt+c`。
- 当前配置关闭了鼠标操作，也关闭了自动保存；修改后记得 `:w`。

## Herdr 中的 Cmd+D 多选

Herdr 的终端快捷键将 `Cmd+D` 转发为 `F12`；Helix 在普通、选择模式下将 `F12` 绑定到“增加选中下一个匹配”。这不是 Helix 原生的 Cmd 键绑定，其他终端不保证适用。

操作流程：

1. 将光标放到目标单词上，依次按 `miw` 选中单词。
2. 在 Herdr 中按 `Cmd+D`；其他环境使用 `Ctrl+d` 或终端可发送的 `F12`。
3. 重复按以增加匹配选区，再按 `c` 输入替换内容。
4. 按 Esc 返回普通模式，按 `,` 仅保留主选区。

`Cmd+D` 在 Shell 中也会发送 F12，不会发送原本可能表示 EOF 的 Ctrl+D。Herdr 侧详见 [Herdr app 快捷键](../../../herdr-app-shortcuts.md)。

## 保存与退出命令

| 命令 | 功能 |
|---|---|
| `:w` | 保存当前文件 |
| `:w 路径` | 将当前内容写入指定路径 |
| `:q` | 退出当前窗口；有未保存修改时会阻止退出 |
| `:q!` | 强制退出当前窗口，可能丢失未保存修改 |
| `:wq` | 保存并退出当前窗口 |
| `:format` | 格式化文档，与当前自定义 `qq` 相同 |

## 常用操作示例

- **修改一个单词**：`miw` → `c` → 输入新词 → Esc。
- **删除整行**：`x` → `d`；删除三行：`3x` → `d`。
- **全文件批量替换**：`%` → `s` → 输入正则 → Enter → `c` → 输入替换文本 → Esc → `,`。
- **快速定位可见单词**：`rr` 或 `gw` → 输入双字符标签。
- **格式化并保存**：`qq` → `:w` → Enter。
